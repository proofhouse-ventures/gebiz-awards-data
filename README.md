# GeBIZ Awards Data (snapshot)

Machine-readable snapshot of Singapore GeBIZ government tender awards, published by data.gov.sg under the **Singapore Open Data Licence v1.0**, kept here as a bootstrap copy for Proofhouse Ventures APIs.

Looking for the usable product? This raw snapshot feeds:

- **GeBIZ Award Intelligence** (Apify Actor): https://apify.com/proofhouse-ventures/gebiz-award-intelligence
- **SG Public Data API — GeBIZ Awards** (RapidAPI): https://rapidapi.com/ProofhouseVentures/api/sg-public-data-api-gebiz-awards
- **Global Company Registry & SG data products**: https://proofhouseventures-site.pages.dev/products/

Source: data.gov.sg — GeBIZ tender awards. Contains public-sector procurement award records (tender, agency, supplier, awarded amount). Redistributed with attribution under the Singapore Open Data Licence v1.0; not endorsed by the Singapore Government.
